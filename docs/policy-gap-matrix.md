## Overview

The ADO Policy API (`_apis/policy/configurations`) manages two categories of policies:

1. **Branch policies** — scoped to a specific branch (or ref pattern) in one or more repositories
2. **Repository policies** — scoped to one or more repositories (project-wide when no repo ID is specified)

All policy configurations share a common envelope (`PolicyConfiguration`) with type-specific settings embedded in the `settings` field. betterado maps each policy type to a dedicated Terraform resource.

### Common PolicyConfiguration envelope

Every policy type shares these top-level fields:

| API field | ADO type | betterado attribute | Coverage | Notes |
|---|---|---|---|---|
| `id` | `*int` | resource ID (via `d.SetId`) | full | Computed; managed as string resource ID |
