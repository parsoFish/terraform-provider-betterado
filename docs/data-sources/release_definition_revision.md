# betterado_release_definition_revision (Data Source)

Use this data source to retrieve a specific historical revision of an Azure
DevOps classic release definition. Useful for auditing changes or comparing
revisions.

## Example Usage

```hcl
data "betterado_release_definition_revision" "v3" {
  project_id            = var.project_id
  release_definition_id = 42
  revision              = 3
}

output "revision_json" {
  value = data.betterado_release_definition_revision.v3.json_content
}
```
