# betterado_build_definition (Data Source)

Use this data source to read the configuration of an existing Azure DevOps build
(pipeline) definition. Useful for referencing pipelines from other Terraform
resources without managing them directly.

## Example Usage

```terraform
data "betterado_project" "example" {
  name = "MyProject"
}

data "betterado_build_definition" "example" {
  project_id = data.betterado_project.example.id
  name       = "My Pipeline"
}

output "build_definition_id" {
  value = data.betterado_build_definition.example.id
}
```
