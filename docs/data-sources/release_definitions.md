# betterado_release_definitions (Data Source)

Use this data source to query and list classic release definitions in an Azure
DevOps project. Supports filtering by name and folder path.

## Example Usage

```hcl
data "betterado_release_definitions" "all" {
  project_id = var.project_id
}

data "betterado_release_definitions" "in_folder" {
  project_id = var.project_id
  path       = "\\Production"
}
```
