## 2. `betterado_security_permissions` (resource)

### 2.1 ADO API Surface

The resource calls two ADO Security REST API endpoints:

| API Endpoint | SDK Method | Usage |
|---|---|---|
| `POST _apis/accesscontrollists` / `SetAccessControlEntries` | `SecurityClient.SetAccessControlEntries` | Create / Update permissions |
| `GET _apis/accesscontrollists` | `SecurityClient.QueryAccessControlLists` | Read current ACL (reconcile + wait) |
| `DELETE` (via SetAccessControlEntries with cleared bits) | `SecurityClient.SetAccessControlEntries` | Delete (clear managed bits) |
| `GET _apis/securitynamespaces/{namespaceId}` | `SecurityClient.QuerySecurityNamespaces` | Resolve action names to bit values |
| `GET _apis/identities?subjectDescriptors=...` | `IdentityClient.ReadIdentities` | Resolve principal subject descriptor → identity descriptor |

## 4. `betterado_security_namespace_token` (data source)

### 4.1 ADO API Surface

| API Endpoint | SDK Method | Usage |
|---|---|---|
| `GET _apis/securitynamespaces` | `SecurityClient.QuerySecurityNamespaces` | Resolve namespace name → UUID |
| Various resource APIs (Build, WorkItemTracking, etc.) | Multiple clients | Token construction for complex namespaces requiring path resolution |

### 4.2 Schema Field vs API Gap Table

This data source generates security tokens for known namespaces — it has no direct ADO "field" mapping to an API response. The schema fields are all inputs to the token-generation logic.

| TF field | Purpose | Status | Notes |
|---|---|---|---|
| `namespace_id` | Input: namespace UUID (mutually exclusive with `namespace_name`) | **mapped** | `ExactlyOneOf` constraint |
| `namespace_name` | Input: namespace name to resolve | **mapped** | `ExactlyOneOf` constraint; resolved via `QuerySecurityNamespaces` |
| `identifiers` | Input: TypeMap of namespace-specific identifiers (e.g. `project_id`, `repository_id`) | **mapped** | Optional; validated per namespace template |
| `return_identifier_info` | Mode switch: return required/optional identifier lists instead of a token | **mapped** | Optional bool; default false |
| `token` | Computed output: generated security token | **mapped** | Computed |
| `required_identifiers` | Computed output: list of required identifier keys for namespace | **mapped** | Computed; only populated when `return_identifier_info = true` |
| `optional_identifiers` | Computed output: list of optional identifier keys for namespace | **mapped** | Computed; only populated when `return_identifier_info = true` |

### Read-only / internal gaps — explicit callout

All `SecurityNamespaceDescription` fields beyond `NamespaceId`, `Name`, `DisplayName`, and `Actions` (`DataspaceCategory`, `ElementLength`, `ExtensionType`, `IsRemotable`, `ReadPermission`, `SeparatorValue`, `StructureValue`, `SystemBitMask`, `UseTokenTranslator`, `WritePermission`) are **intentionally excluded** — they are low-value bookkeeping fields that TF practitioners do not need to reference.
