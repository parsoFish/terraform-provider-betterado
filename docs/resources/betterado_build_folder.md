# betterado_build_folder (Resource)

Manages an Azure DevOps build folder. Build folders organize build definitions
into a logical hierarchy beneath the root `\` folder.

## Example Usage

```terraform
data "betterado_project" "example" {
  name = "MyProject"
}

resource "betterado_build_folder" "example" {
  project_id  = data.betterado_project.example.id
  path        = "\\MyFolder"
  description = "Folder for pipeline definitions"
}
```

## Schema

### Required

- `path` (String) The folder path within the build definitions tree (e.g. `\MyFolder`).
- `project_id` (String) The ID of the project the build folder belongs to.

### Optional

- `description` (String) The description of the build folder.

### Read-Only

- `id` (String) The project ID of the build folder resource.
