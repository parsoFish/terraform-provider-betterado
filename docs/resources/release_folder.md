# betterado_release_folder (Resource)

Manages a folder in the Azure DevOps release definitions hierarchy. Folders let
you organize release definitions and apply permissions at the folder level via
`betterado_release_definition_permissions`.

## Example Usage

```terraform
data "betterado_project" "example" {
  name = "ExampleProject"
}

resource "betterado_release_folder" "example" {
  project_id  = data.betterado_project.example.id
  path        = "\\MyFolder"
  description = "Folder for MyFolder release pipelines"
}
```
