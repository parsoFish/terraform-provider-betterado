# betterado_pipeline_authorization (Resource)

Manages pipeline authorization for a protected resource (such as a service connection,
agent pool, environment, or variable group) in Azure DevOps. Authorized pipelines
may access the resource without per-run approval prompts.

## Example Usage

```terraform
data "betterado_project" "example" {
  name = "MyProject"
}

resource "betterado_agent_pool" "example" {
  name           = "my-pool"
  auto_provision = false
  auto_update    = false
}

resource "betterado_agent_queue" "example" {
  project_id    = data.betterado_project.example.id
  agent_pool_id = betterado_agent_pool.example.id
}

resource "betterado_pipeline_authorization" "example" {
  project_id  = data.betterado_project.example.id
  resource_id = betterado_agent_queue.example.id
  type        = "queue"
}
```

## Schema

### Required

- `project_id` (String) The ID of the project.
- `resource_id` (String) The ID of the resource to authorize.
- `type` (String) The type of the resource. Valid values: endpoint, queue, variablegroup, environment, repository.

### Optional

- `pipeline_id` (Number) The ID of the pipeline to authorize. If omitted, all pipelines are authorized.
- `pipeline_project_id` (String) The ID of the project where the pipeline resides (if different from project_id).

### Read-Only

- `id` (String) The ID of the pipeline authorization resource.
