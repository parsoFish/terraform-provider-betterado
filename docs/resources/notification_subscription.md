# betterado_notification_subscription (Resource)

Manages an Azure DevOps notification subscription — a rule that delivers
event-driven notifications (e.g. work item changes, build completions, pull
request updates) to a delivery channel such as email or a service hook.

Each subscription binds an event type (`subscription_type`), a delivery channel
(`channel_type`, `channel_address`), an optional expression filter, and a
subscriber identity to a project scope.

## Example Usage

```terraform
# Look up an existing project to scope the subscription.
data "betterado_project" "example" {
  name = "my-project"
}

# Look up the subscriber identity.
data "betterado_identity_user" "subscriber" {
  mail = "team@example.com"
}

# Create an ADO notification subscription that sends an email
# when a work item is changed in the project.
resource "betterado_notification_subscription" "example" {
  project_id        = data.betterado_project.example.id
  subscription_type = "ms.vss-work.workitem-changed-event"
  subscriber_id     = data.betterado_identity_user.subscriber.id
  channel_type      = "EmailHtml"
  channel_address   = "team@example.com"

  # Optional: override filter type (defaults to "Expression")
  filter_type = "Expression"
}
```

## Schema

### Required

- `channel_type` (String) Delivery channel type (e.g. `EmailHtml`, `ServiceHooks`).
- `project_id` (String) The ID of the Azure DevOps project that scopes this subscription.
- `subscriber_id` (String) The subscriber identity descriptor or group descriptor.
- `subscription_type` (String) The event type ID (e.g. `ms.vss-work.workitem-changed-event`).

### Optional

- `channel_address` (String) Email address for EmailHtml channel. Leave empty for other channel types.
- `filter_criteria` (String) Serialised expression criteria (JSON string).
- `filter_type` (String) Filter type identifier. Defaults to `Expression`.

### Read-Only

- `id` (String) The ID of the notification subscription.
- `status` (String) Subscription status returned by the API.
