## Overview

The ADO Pipelines Checks API (`_apis/pipelines/checks/configurations`) manages approval gates and automated checks that run before a pipeline can access a protected resource (environment, service connection, agent pool, repository, secure file, or variable group).

betterado models these as individual Terraform resources backed by `CheckConfiguration` objects. All resources share a common base schema and diverge only in their `settings` payload.

### Common `CheckConfiguration` envelope

Every check type shares these top-level fields:

| API field | ADO type | betterado attribute | Coverage | Notes |
|---|---|---|---|---|
| `id` | `*int` | resource ID (`d.SetId`) | full | Computed integer ID |
| `type.id` | `*uuid.UUID` | hardcoded per resource | full | Fixed per check type; not user-configurable |
| `type.name` | `*string` | — | none | Read-only display name; not needed in TF |
| `settings` | `interface{}` | type-specific fields | full | Type-specific payload (see per-check sections) |
| `resource.id` | `*string` | `target_resource_id` | full | Required; resource being protected (UUID or name) |
| `resource.type` | `*string` | `target_resource_type` | full | Required; one of `endpoint`, `environment`, `queue`, `repository`, `securefile`, `variablegroup` |
| `resource.name` | `*string` | — | none | Read-only display name; not needed in TF |
| `timeout` | `*int` | `timeout` | full | Optional (resource-specific defaults); minutes |
| `version` | `*int` | `version` | full | Computed; used internally for optimistic concurrency |
| `url` | `*string` | — | none | Read-only REST URL; out of scope |
| `_links` | `interface{}` | — | none | Read-only REST nav links; out of scope |
